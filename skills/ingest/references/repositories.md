# Repositories

Resolve repository identity and the exact commit/revision actually read.
Keep README, source quotations, file inventory, license evidence and selected change range distinguishable.
An inventory is not the content of its listed files; branch names without a read revision do not prove a pinned source.
Retain original code attribution and do not copy implementation into another product without verified rights.

The owner-selected reusable tool object is different from an automatic repository candidate.
Use the owner's stated reason for saving it and the actual tool template/placement; arrival of a GitHub event is not that selection.
Create no personal catalog note as a side effect.

Synthesize observed structure, reusable mechanisms, risks and limits with exact file/revision anchors.
Do not execute repository scripts, install dependencies or fetch unrelated branches as an ingest side effect.
